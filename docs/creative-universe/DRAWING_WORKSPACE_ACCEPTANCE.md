# Drawing Workspace and connected activities

The production-bundle application source for this review is `e9b4332432e90359deb9cd4f5f7d030a7a2a3f35`. Start at **My Art → Draw here**. For a short review, choose **Thing**, draw and name **My Rock**, then select **Keep my art**. Choose **Make a scene** to use the saved version. Return to My Art, open **Keep drawing**, change a mark and keep another version. Reopen the first scene to see the original rock.
