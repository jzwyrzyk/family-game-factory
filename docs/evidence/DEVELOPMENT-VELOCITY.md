# Development validation and execution inventory

## Editing and handoff

Run `npm run check:changed` from the repository root after installing the locked dependencies and Playwright Chromium. `-- --plan` explains the actual branch and working-tree selection. `-- --base REF` selects another integration base. `-- --domain NAME` adds navigation, artwork, coding, games, math, english, coach, generated, storage or security. Shared, deleted, sensitive and unclassified executable paths take the broader route. The coverage map includes integration consumers and checks dependency changes in eligible source leaves. A focused browser loop builds the current working tree once. Inspect failures in the command output and screenshots in `test-results/`.

For a candidate, link the head, prospective merge, changed journeys, offline review download, pending checks and acceptance gaps. For integration, verify base/head parents, tree, first-attempt required results and preserved evidence. For release, resolve fresh environment eligibility and exact tested source, artifacts, configuration, private worker and acceptance. [Environment contract](../development/DEV-TEST-PROD.md)

## Execution inventory

The linked workflows specify the exact command lines, flags, runner, environment, fixtures, checkout, output paths and conditions. The [Arcade assignment](../../scripts/ci/suites.json) expands against the [locked-source scripts](../../package.json). Print every leaf and owner from the repository root:

```sh
node --input-type=module -e "import {readJSON,expandCommands} from './scripts/ci/suites.mjs'; const pkg=readJSON('package.json'); for(const [id,s] of Object.entries(readJSON('scripts/ci/suites.json').shards)) for(const command of expandCommands(s.commands,pkg.scripts)) console.log(id,JSON.stringify(command))"
```

Unless overridden in the linked definition, PR checkout is the GitHub prospective merge, push checkout is the pushed SHA and manual checkout is the selected ref. Visual and Arcade PRs use Ubuntu 24.04, Node 22, the same lockfile, CI headless Playwright Chromium, a clean Vite production build with relative paths and local fixtures. The four shared visual commands start their own local server/browser and write screenshots, and the locked npm Gem Factory script expands to the single browser command. Brand, Studio and Delight are in the studio-core receipt; Gem Factory is in factory. Their images remain in the corresponding source/run/attempt Arcade evidence archive. The gallery has its own visual result; success there only establishes the gallery.
