## Current-notice renewal and supervised early creation

A verified existing guardian whose privacy or participation notice is stale can renew at `/renew-participation` using the same trusted device and parent passphrase. Renewal retains the guardian, device and saved work, revokes prior optional processing choices, cancels pending jobs and clears play receipts. A new play acknowledgment and separately verified optional choices remain necessary. Pending verification, suspended accounts and deletion cases cannot use renewal as recovery.

The six immutable grade values remain `-1, 0, 1, 2, 3, 4`. Beta Parent Controls save only the selected grade and compare-and-swap version per anonymous profile in the family directory; learning responses and history remain local unless separately authorized continuity is enabled. Server metadata wins on application entry. Missing server settings cannot authorize creative submissions. Normal builds continue to hold early grades. `node scripts/beta/build.mjs --early-preview` produces the named synthetic preview; enabling it does not enable supervised processing.

Both `earlyLearningPreview` and `parentGuidedCreation` must be explicitly true before an early learner can start **Make together**. These configuration options default off. The verified parent first selects that learner's grade, independently obtains each requested processing scope, and explicitly starts supervision. A random proof exists only in that tab's memory; its server digest binds the learner, trusted device, guardian, grade version, current notices, renewal epoch and exact verified privacy choice. Its expiry is bounded by fifteen minutes and the parent/device sessions. Profile switching, reload and expiry clear the tab proof. Every creative workspace transaction checks current authority; queued jobs retain server-owned learner and supervision provenance. Grade changes, consent replacement, notice renewal, expiry and revocation prevent continued processing, with outstanding reservations conservatively settled.

The supervision controls mount in the local Parent settings panel independently of the remote builder configuration request. A slow or unavailable workshop must not permanently omit them. This changes neither the default-off gate nor the separate verified processing scopes.
