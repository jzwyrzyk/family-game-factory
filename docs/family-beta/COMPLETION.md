# Private family beta and F06 integrated acceptance

This is the combined requirement and evidence register for the November 25, 2026 completion assignment. It accompanies the existing [family architecture](ARCHITECTURE.md), [storage architecture and efficiency report](../storage/README.md), [domain inventory](../storage/INVENTORY.md) and [single activation runbook](ACTIVATION.md). It is not a second architecture or an authorization to release.

**Evidence rule:** complete means the stated repository criterion has source and a passing check on the integrated candidate. Partial means source, integration or evidence is still missing. Failed means an observed check failed. Externally blocked means the missing step actually needs an external system, policy decision, hardware or approval. Not applicable means a requirement does not apply to that surface, with a reason. There is no weighted production-readiness score. An inherited green PR is evidence only for its recorded source.
