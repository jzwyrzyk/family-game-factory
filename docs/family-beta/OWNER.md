# Private Family Beta — Owner Operating Guide

Before inviting a real family, complete the [activation and rollback checklist](ACTIVATION.md) for the selected environment.

Use the approved management address ending in **/manage**. Sign in with the designated operator account. Keep the operator passphrase separate from any family passphrase. Every change shows the target family and asks for confirmation. Use a private reference such as workshop-04 for your own contact book. Keep real contact details and verification evidence in the separately approved, access-controlled operator system.

## Invite a grown-up

1. Check that the activation checklist has been signed for this environment. In **Platform controls**, check family participation and invitation status. The spending stop can stay on for a local-only family.
2. Choose **Create family**. Select the family, then **Issue or replace invitation**. Send the workshop address and the one-time code privately using the established adult contact. Replacing the code immediately invalidates its predecessor. A new-family or recovery code lasts 24 hours.
3. The adult opens the family address, chooses **I have an invitation**, reads the notices and chooses the parent passphrase. They receive a pairing code. Contact the intended adult independently using the existing contact record. Match the pairing code for that device, complete your reviewed participation procedure, and record its unique reference with **Confirm guardian participation**.
4. The grown-up selects **Family login**, unlocks **Family privacy and profiles**, and adds an explorer. The system creates a random profile ID. Use workshop nicknames. Each new play session requires all three acknowledgments and the parent passphrase. Ordinary moves between games keep the same play session.
5. To connect another tablet, a grown-up opens **Family privacy and profiles**, unlocks management and creates a ten-minute device code. On the new device use **Family login → Connect a trusted device** with that code and the family's existing passphrase.

## Authorize a feature or a budget

In **Features and spending**, select the local activities and the monthly allowance in dollars. New families start with zero spending, remote AI paused, generation paused and remote permissions off. Adult Private remains exclusive to the owner household. Adult game importing awaits a separately released implementation.

For optional processing, send the direct notice privately. Have the grown-up choose exact scopes in their own family controls. Check the notice version, scope and pending choice. Complete the independently reviewed guardian verification procedure for that choice, then use **Record verified consent**. Use a distinct external receipt reference. Do not upload identity documents. Verify the environment's current provider and child-safety evidence before enabling the chosen capability. A parent acknowledgment or provider request setting cannot supply that evidence.

Review the family and global allowances, release the appropriate pause, and check provider readiness. Lowering a limit below outstanding use stops new admissions. Review **Usage and pending reservations** for this month and the preceding twelve months. A reservation can cover a provider call whose result has not returned. Use the original job's read-only status lookup after a network loss. Never initiate another paid job merely to discover its status.

For artwork, review the exact non-identifying PNG privately and record its SHA-256 in **Approve exact artwork** for that family. Enable **Reviewed adult artwork**. The grown-up unlocks family management and uses the reviewed artwork input in play. Only the file digest is sent for authorization. The browser checks size and dimensions and re-encodes the reviewed pixels locally. It admits the selected PNG as the original only when the selected bytes and the fresh raster have identical SHA-256 digests. The library keeps those exact selected bytes. Filenames, source metadata and editable PNG attachments cannot enter this way.

When the prepared copy differs, the grown-up can download **workshop-picture.png** and keep the outside source file privately. Review the new PNG through the same private channel, approve its exact digest and choose that file on the preparing device. A different browser encoder can produce a different file and require its own review. The file selection does not save a drawing until admission succeeds. Older beta entries retain the raster bytes originally admitted. Recovering an earlier outside file requires the family's own retained copy.

## Stop access or respond to a privacy request

- **End play** closes the current grant. **Forget device** also removes its trust. A grown-up or operator can revoke a missing tablet. To recover a passphrase, verify the original adult using the approved channel, choose **Start credential recovery**, then pair and verify again. Saved work remains in the original family.
- **Pause generation** blocks further generation admission. **Pause all remote AI** keeps local activities available. **Stop all beta AI spending** stops new paid reservations across linked families and the explicitly mapped household. Review pending reservations until settled. Uncertain provider use is accounted for conservatively.
- **Suspend access** ends the family's play grants and withdraws processing. Resume after independent review. **Permanently revoke access** retires the family access path. Never reuse the address or family ID.
- Verify the requester before disclosure or erasure. Choose **Request family export**, then confirm the release for that exact case. For 24 hours the authorized guardian can use **Download approved family export** in family controls or `/privacy-export` on the family address. A suspended family's login opens this limited export page after release. Its existing trusted device and parent passphrase unlock only that case for up to fifteen minutes; play, management and optional processing stay paused. Revoked families or devices cannot use this path. The dashboard never displays game prompts or child conversations. Browser-only work requires the family's local backup on each device.
- **Request family deletion** suspends the family and stops affected jobs. Settle outstanding reservations, verify custody, and inform the family of irreversible effects, device copies and backup expiry. Confirm the case in the dashboard. The restricted privacy operator executes the exact approved case. Retain a minimal completion receipt, confirm backup and soft-delete expiry separately, and privately notify the guardian.

An approved family export includes the server workspace, paged acknowledgment receipts and monthly usage. A grown-up completes the download on each original family device to include its local records. The download reports when a device inventory needs separate recovery. The operator dashboard shows the type, stage, amount and opaque reference of outstanding reservations.

Each invited pilot account has one independently verified guardian. Additional trusted devices belong to that guardian. Keep the guardian passphrase private. Provider readiness shows the configured dispatch and service connections, scoped evidence expiry, and the effective per-game ceiling from the mounted configuration. Actual provider availability and independent approvals have their own release evidence.

When an existing guardian sees **Updated family notices**, they use their current device and parent passphrase to renew. They do not need a replacement invitation or destructive recovery. Renewal clears previous play acknowledgments and optional processing permissions; independently review and verify any new optional choices before enabling them again. A pending deletion case shows only its deletion controls and reservation status.

In the named early-learning preview, all six grades can be selected through Parent Controls. The family directory retains the anonymous explorer's grade and version so another authorized device cannot bypass its creation rules. Learning answers and history remain on the device unless separately authorized continuity is selected. **Make together** remains closed by default. In a separately approved supervised preview, a parent unlocks controls, selects the early learner and explicitly starts a session after the required processing choices are independently verified. Stay with the learner; end supervision from the same panel. A session lasts at most fifteen minutes, and switching explorers or reloading closes that tab's access. Starting supervision alone never starts a paid build.

If the verified deletion check reports **pending storage operations**, no destructive work begins. Resolve the exact admitted backup or restore operation before retrying; a process crash or elapsed deadline does not prove an upload has stopped. Successful settlement can finish after the family has been suspended, but the deletion state prevents new admissions. The completed case removes scheduled-backup metadata as well as the workspace and continuity records. Approved guardian exports include the corresponding storage-choice and backup-operation history.
