# Synthetic art in playable game tests

These are Chromium captures of a locally packaged, reviewed generated-module-v2 source fixture. The originals were authored for this test. Run `npm run test:game-art` to repeat it. The test compares actual initial canvas pixels to a direct composite from the four exact input PNGs and exercises the movement and scoring rules.

- [First valley flight](valley-first-round.png) shows the rocket player, rock in two roles, dragon and selected background.
- [Faster flight](valley-improved-round.png) shows an improved test with the same five immutable pins.
- [Rocket in Gem Factory](workshop-rocket.png) shows the synthetic picture over the approved illustrated workshop.
- [Phone game idea](phone-game-pictures.png) shows the saved roles and the child's optional action.

The program comes from the local review package. Paid generation, authenticated hosted delivery, physical-device testing and independent release approval have separate gates.
