# Private artwork in 2D play

## Trusted host games

In My Art, select an original picture or saved cutout and choose **Make a picture hunt**. The host creates an editable 2D game on the Creative Studio shelf. The child presses Play and finds the drawing in three positions. Each tap updates a local count. The third displays the finish message. Play resets the game. On a keyboard, **Try tap** activates the selected actor. The existing Rally creation route accepts an explicitly selected compatible car rig and pins the physical version independently.

The picture hunt uses the existing scene language, interpreter, workspace, undo, drafts, Keep, copies and scene-with-art backup. A host lookup checks the active profile and content hash before rendering. New pictures, names and movement revisions do not advance an existing game. Under **More tools → Scene settings → Change picture**, selecting another retained version changes only the actor’s artwork in this draft. Keep records a version. Earlier versions retain the original pin. This works for editable local companion scenes imported from a generated game as well as picture hunts.

The picture hunt declares its target as a collectible. The actual action, count, position changes and payoff are ordinary editable blocks. Changing **Role here** to decoration preserves those blocks. The asset’s category, semantic identity, drawing, name and other uses remain independent. Old scene records may omit the contextual role. The parent learning host continues to control checkpoints. Completing a hunt does not create a learning assessment or Pal reward.
