# PR #43 — code integration and evidence handoff

**Scope:** research-enabled Game Intelligence code; production and paid-model activation explicitly excluded.

## What the code actually implements

- O1–O2: bounded, source-backed child-intent and minimum-sufficient 2D/rules/physics advice, marked uncertain when requirements cannot be established.
- O3–O4: authored functional requirements, honest NOT_TESTED workability status and reuse of the existing authenticated private generation, revision and budgeting pipeline.
- O5: independently authored real-input sandbox/browser probes for sticker rocket, robot grid and physical car, plus broken controls/missing-payoff negatives; the public build request cannot supply the independent acceptance plan.
- O6: one existing bounded repair coordinator, sanitized source-free diagnostics, up to two repairs after generation, same independent retest, no false Ready or automatic Keep.
- O7: fixture-backed Create/Play/Modify/Compare/Keep/Return and learning/host regression journeys; not a substitute for actual device, paid-provider or arbitrary-game testing.

## Evidence and merge requirements

The exact commit being merged must pass strict TypeScript and unit contracts, the independent Game Intelligence contract workflow, browser/learning/creative suites, trusted-device security, brand/joy, Studio, private-coach image and child/learning integration. A green build must never be described as proof of child delight or educational improvement. Earlier green source-branch runs do not replace the final integrated-head checks.

PR #43 includes a merge commit with `main` after #36 and #42. Overlapping source, test, and script changes were reconciled to retain the verified session/device checks, default-off private coach/speech gates, and independent gameplay testing. The approved existing worker SHA, its WIF/IAM settings and the production rollout were deliberately left unchanged.

## Explicitly unproven / outside code merge

- Accurate understanding of arbitrary child ideas, real paid-model generation success, repair yield, P50/P95 latency, cost and unseen-case false positive/negative rates (O8).
- Full tablet/iOS/Android touch and microphone acceptance, real private-coach service and third-party provider processing; guardian consent, Zero Data Retention, parental/privacy approvals and app monitoring are separate gates.
- Rebuilding and security-reviewing the production sandbox image, updating the approved private worker pin, staging then live rollout, rollback rehearsal and supervised family acceptance (O9).
- Universally verifying every game without an independently authored test plan; source heuristics are not a reliable substitute for grounded playtesting.

**Decision boundary:** Merging this reviewed code is an integration milestone, not a go-live authorization or a claim of production reliability across arbitrary user-generated games.
