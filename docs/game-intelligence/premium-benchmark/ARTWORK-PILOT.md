## Implemented and reproducible

New premium planning requests include a versioned art direction beside the source-bound v2 design. It records view, palette and light, scenery, free action space, foreground ordering, required live IDs, motion/pose, display dimensions, normalized pivots and contact width. Required sheet cells, existing approved art, optional accents and native effects have distinct supply values. The constructor receives the validated plan and exact raster metadata. Saved v1 and previous v2 plans still read. All extracted images use the existing `game-assets-v1` reader, preview CSP, sandbox limits, scene commands and independent review. Keep compatible gateway readers installed through rollback.

A private image approval must specifically include `sheetFormat: rgba8-png-grid-v1` before the planner can request that format. The pilot admits one background and one transparent sheet, or existing assets. The sheet is one image allowance. The fixed 1024-square PNG uses 8-bit noninterlaced RGBA, lossless filtering and a uniform, evenly divisible row-major grid with at most seven occupied cells. The extractor validates the actual compressed stream and scanlines, undoes the PNG filters, rejects nontransparent borders, insufficient opaque content and disconnected silhouettes, and retains the full cell to preserve pivots. Every output has its own PNG and SHA-256. Its provenance binds the request/layout/ID digest and original sheet digest. A complete matching set can be reused without another image call. Pixel topology cannot identify two intentionally touching painted characters as separate semantic objects. The reviewer must reject visually fused subjects, wrong poses, unclear controls or unobserved actions.

Only the authorized base revision enters planning and reuse. Raster bytes never enter generated code. The normal submission rejects foreign family/profile revisions before reservation. The private drawing store and its immutable versions stay local. This release adds no upload or authorization to send drawings to a provider. Changing a mechanic preserves approved artwork. The five styles and rule/physics choice remain independent of projection. Essential free orbit and true spatial navigation require a creator decision.
