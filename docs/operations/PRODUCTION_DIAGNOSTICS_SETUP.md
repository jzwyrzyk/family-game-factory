## Trust and cost decision

The three application services already generate Cloud Run platform request logs. A custom view in the bucket that **already holds** those logs can show retained entries predating the view. The existing `jems-diagnostics/views/cloud-run-errors` design drops successes and restricts `httpRequest`. Logging views select entries. Bucket-level field restrictions can hide a whole URL field, but cannot expose a canonical route while hiding the rest of the same URL. An Observability Analytics view also requires access to its underlying log view. [Log views](https://docs.cloud.google.com/logging/docs/logs-views) · [Restricted fields](https://docs.cloud.google.com/logging/docs/field-level-acl) · [Analytics security](https://docs.cloud.google.com/logging/docs/analyze/data-security-with-analytics)

The broker is the trusted code inside Google Cloud. Its runtime identity can read the custom **request-only** view, including sensitive fields within the selected entries if the existing bucket permits them. Review the source, build path, deployed revision, ability to change that revision and controls on who can impersonate its identity. The fixed Google API response projection limits what enters its memory. Its route allowlist protects what leaves it. GitHub's identity gets only invocation of this function. A URL may contain private path segments or query parameters, so even partial responses must stay out of logs, exceptions, traces and support captures.

There is no additional log-routing sink, raw log copy or retention extension in this plan. Budget for Cloud Run invocation/compute, routine broker platform logs, the one-time Cloud Build and Artifact Registry storage, possible network charges and GitHub-hosted runner/artifact usage. Minimum instances zero limits idle costs. Maximum instances one limits concurrency and is not a spending cap. Obtain an estimate from actual traffic and project billing before enabling recurring queries. [Cloud Run pricing](https://cloud.google.com/run/pricing) · [Observability pricing](https://cloud.google.com/stackdriver/pricing) · [Source builds](https://docs.cloud.google.com/run/docs/deploying-source-code)
