# Rewards interface captures

These images show the implemented application using an isolated synthetic browser profile. The browser test earned its rewards through the normal Math, English, game-development and scene-challenge interfaces; it did not inject gem grants.

- [Desktop rewards page](rewards-desktop.png)
- [Mobile rewards page](rewards-mobile.png)
- [Learning reward in context](learning-reward.png)

The page capture shows 92 lifetime gems and the earned Gem Polisher rank. The learning capture shows a 2-gem reward for a correct answer completed with help; the original learning evidence remains assisted. The test subsequently verifies 100 gems after a distinct coding challenge, backup round trips and profile separation.

Reproduce with `npm run build` followed by `node tests/rewards-browser.cjs`. These are browser-emulated observations, not child-use research, physical-device acceptance or deployed-site evidence.
